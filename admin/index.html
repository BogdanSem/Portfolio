Підключення до GitHub (один раз)

Адмінка зберігає зміни прямо в ваш репозиторій на GitHub, і сайт оновлюється сам за 1–2 хвилини. Для цього потрібен ключ доступу:

  1. Відкрийте github.com/settings/personal-access-tokens/new.
  2. Token name: portfolio admin. Expiration: оберіть потрібний строк, наприклад рік.
  3. Repository access → Only select repositories → оберіть репозиторій сайту.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Натисніть Generate token, скопіюйте ключ (починається з github_pat_) і вставте нижче.

Ключ зберігається тільки в цьому браузері на цьому компʼютері. Не відкривайте адмінку з ключем на чужих пристроях.
