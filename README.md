# Сайт-портфоліо Bohdan Semchyshyn

Простий статичний сайт: без сервера, без бази даних, без платних сервісів. Відео відтворюються в плеєрі Vimeo прямо на сторінці.

## Що де лежить

```
index.html          головна сторінка
project.html        сторінка проєкту (одна на всі проєкти)
data/site.js        УВЕСЬ КОНТЕНТ: проєкти, відгуки, контакти, шоуріл
assets/style.css    дизайн
assets/app.js       логіка (плеєри, фільтри, слайдер before/after)
img/<slug>/         обкладинка cover.jpg і кадри 01.jpg, 02.jpg…
```

Майже все, що вам треба буде міняти, лежить у `data/site.js`. Відкривайте його в будь-якому текстовому редакторі (найзручніше VS Code, він безкоштовний).

## Як додати або змінити відео

Найпростіше це робити в адмінці (див. нижче): кнопка «+ Додати відео» або «Редагувати» на картці. Там змінюються назва, посилання на Vimeo, клієнт, роль, формат, тривалість, The brief, What I did, відгук, обкладинка й кадри.

Кожне відео на сайті — окремий проєкт. Вертикальні відео (9:16) показуються в стрічці Social, горизонтальні — в сітці Work. Якщо відео є частиною іншого проєкту (наприклад, нарізка для Reels з великого ролика), у полі «Частина проєкту» оберіть головний проєкт, і вони показуватимуться разом у блоці «More from this project».

Усі дані лежать у `data/site.js`, його можна редагувати й вручну. Якщо після ручної правки сторінка порожня, найчастіше причина в загубленій комі чи лапці.

## Адмінка: порядок робіт, обкладинки і кадри

Адмінка відкривається за адресою сайту з `/admin/` у кінці, наприклад `https://логін.github.io/portfolio/admin/`. На сайті посилання на неї немає, і пошуковики її не індексують.

**Перше підключення (один раз):**
1. Відкрийте github.com/settings/personal-access-tokens/new.
2. Token name: `portfolio admin`, Expiration: наприклад рік.
3. Repository access → Only select repositories → репозиторій сайту.
4. Permissions → Repository permissions → Contents → Read and write.
5. Generate token, скопіюйте ключ і вставте його в адмінці разом з назвою репозиторію (`логін/назва`).

Ключ зберігається тільки в цьому браузері. Коли строк ключа закінчиться, створіть новий так само.

**Що можна робити:**
- Перетягувати картки, щоб змінити порядок. «Work» — це сітка робіт, «Social» — стрічка шортсів (проєкти з `vertical: true`).
- «Обкладинка і кадри»: відкрийте відеофайл проєкту з компʼютера, знайдіть кадр (← → по кадру, Shift — по секунді), натисніть C, щоб зробити його обкладинкою, або F, щоб додати у вибрані кадри. Кадри можна переставляти і прибирати.
- «Опублікувати» записує всі зміни на GitHub одним комітом, і сайт оновлюється за 1–2 хвилини.

Без інтернету можна працювати з копією сайту на компʼютері: кнопка «Працювати з папкою на компʼютері» (лише Chrome або Edge).

## Як перевірити зміни у себе на компʼютері

Відкрийте `index.html` подвійним кліком у браузері. Плеєри Vimeo можуть не запускатися з файлу на диску, але після публікації працюють.

## Як опублікувати сайт безкоштовно (GitHub Pages)

1. Зареєструйтесь на github.com.
2. Натисніть **New repository**. Назва: `ваш-логін.github.io` (наприклад `semchyshyn.github.io`). Тип **Public**. Натисніть **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file** і перетягніть туди **вміст** папки сайту (файли `index.html`, `project.html`, `README.md` і папки `assets`, `data`, `img`, а не саму папку). Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages**. У **Source** оберіть **Deploy from a branch**, гілку `main`, папку `/ (root)`, **Save**.
5. Через 1–2 хвилини сайт буде доступний за адресою `https://ваш-логін.github.io`.

Щоб оновити сайт пізніше: відкрийте потрібний файл на GitHub, натисніть олівець (Edit), внесіть зміни, **Commit changes**. Нові зображення завантажуйте через **Add file → Upload files** у потрібну папку.

## Власний домен (за бажанням)

Купіть домен (наприклад, на Namecheap або Porkbun, приблизно $10–15 на рік), потім у GitHub **Settings → Pages → Custom domain** впишіть його і виконайте інструкцію з налаштування DNS, яку покаже GitHub.

## Налаштування у Vimeo

Щоб відео відтворювалось на сайті, у кожного відео на Vimeo: **Settings → Privacy → Where can this be embedded?** має бути **Anywhere** або домен вашого сайту.
